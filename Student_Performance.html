Student Performance Dashboard

How each student is doing across the ASCEND curriculum — module quizzes, NBME customized assessments, OSCE and clinical-skills evaluations, and NBME subject (shelf) examinations — for faculty advising, coaching, and promotions review. Students appear by code; names are held in a separate key.

⚠ Sample data. These are computer-generated, coded students, not real records. Use Load data file to replace them with a registrar or assessment export (JSON or CSV — the expected shape is in the comment block at the top of this file’s script).
🔒 Coded education records. Students appear by code only — no names and no portraits are held in or shown by this dashboard. The code-to-student key is kept separately by the Office of Curricular Affairs. Because that key exists these records are still re-identifiable and remain protected under FERPA: open only the students you have a legitimate educational interest in, never pair this page with the key in a shared channel, and do not leave it open on an unattended screen.
