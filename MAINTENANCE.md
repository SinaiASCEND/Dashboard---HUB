# Maintaining the ASCEND dashboards

The maintainer is not expected to touch code. The division of work:

**Maintainer** — puts new or updated source files (spreadsheets, PDFs, exports, Word documents) in OneDrive `Curricular Affairs - Documents/# Dashboards/# SOURCES/`, in the numbered folder for that dashboard (each has a READ ME saying what belongs there), then asks Claude Code in plain words, for example "Update the Phase 2 dashboard from the sources folder."

**Claude Code** — reads the sources, regenerates or hand-derives the dashboard's data files, opens and merges the pull request, verifies the live page, keeps the sources folder organized, and reports back in plain language.

The full map of where every dashboard's data lives, its build scripts, access codes and retired repos is in the ASCEND Dashboards Maintainer Guide (a shared Claude Doc kept by the Office of Curricular Affairs); its Technical reference tab is the one Claude Code works from.
